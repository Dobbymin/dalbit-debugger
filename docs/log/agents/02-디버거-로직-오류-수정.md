# 02. 디버거 로직 오류 수정

## 사용한 에이전트 도구
- `read_file`
- `write_file`
- `replace`

## 위임 범위와 판단 근거
- `src/pages/debugger/DebuggerPage.tsx`의 기본 예제 코드 문법 오류 수정
- `src/features/debugger/_hooks/useDebugger.ts`의 변수 추출 로직 및 이벤트 핸들링 보강
- 출력 로그 및 변수 상태가 실시간으로 업데이트되지 않는 문제 해결

## 검증 방법
- `pnpm run lint`: 린트 오류 없음 확인
- `pnpm run build`: 빌드 및 타입 체크 성공 확인
- 수동 검증 시나리오: `나이 : 20` 예제 코드가 단계별 실행 시 로그에 `1번 줄 실행 중...`, `[출력] 성인입니다` 등으로 표시되는지 확인

## 교정 사항
- `DebuggerPage.tsx`의 기본 예제 코드가 `나이 = 20`으로 잘못되어 있어 `나이 : 20`으로 수정함.
- `useDebugger.ts`에서 변수 추출 시 `Map`과 `Object` 구조를 모두 지원하도록 개선하고, `any` 없이 `ValueType` 클래스 타입을 활용하도록 교정함.
- 로그 메시지에 `[출력]`, `[에러]` 태그를 추가하고 단계 실행 시 현재 실행 줄 정보를 출력하도록 보강하여 PRD 요구사항을 충족함.
