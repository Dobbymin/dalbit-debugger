# 21. 디버거 동기화 무한 초기화 버그 수정

## 사용한 에이전트 도구
- `read_file`: 현재 코드 상태 확인
- `replace`: 의존성 배열 수정

## 위임 범위와 판단 근거
- `src/features/debugger/_hooks/useDebuggerSync.ts` 파일의 `useEffect` 의존성 배열 수정
- 사용자가 에디터에 타이핑할 때마다 `code`가 변경되어 `useEffect`가 재실행되고, `initialCodeFromLocation`이 있을 경우 계속 초기 코드로 덮어씌워지는 버그 해결을 위해 `code`를 의존성 배열에서 제거

## 검증 방법
- `npm run lint` 및 `tsc`를 통한 정적 분석 확인
