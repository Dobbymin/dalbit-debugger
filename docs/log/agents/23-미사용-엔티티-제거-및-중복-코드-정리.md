# 23. 미사용 엔티티(debug-session) 제거 및 중복 코드 정리

## 사용한 에이전트 도구
- `grep`: `src/` 내 사용처 확인
- `run_shell_command`: 미사용 디렉토리 삭제

## 위임 범위와 판단 근거
- `src/entities/debug-session/` 디렉토리 전체 삭제
- `useDebugSession` 훅과 관련 타입들이 `src/features/debugger/`의 로직과 중복되며, 실제 코드에서 전혀 사용되지 않고 있음을 확인 (문서에서만 언급됨)
- 유지보수성 향상을 위해 중복된 미사용 코드 제거

## 검증 방법
- `npm run lint` 및 `tsc`를 통한 정적 분석 확인 (사용처가 없음을 사전에 `grep`으로 확인)
