# 10. 예제 라이브러리 연동 및 코드 주입 구현

## 사용한 에이전트 도구
- sequential-thinking
- codebase_investigator
- read_file
- write_file
- replace

## 위임 범위와 판단 근거
- **분석**: `codebase_investigator`를 사용하여 `/debugger` 페이지의 코드 로드 방식을 분석했습니다. 현재 하드코딩된 방식을 확인하고 외부 주입이 필요함을 판단했습니다.
- **설계**: `ExamplesPage`에서 `useNavigate`를 통해 코드를 전달하고, `DebuggerPage`에서 이를 받아 에디터에 로드하는 방식을 설계했습니다.

## 검증 방법
- `ExamplesPage`에서 "디버거에서 열기" 클릭 시 `/debugger` 페이지로 이동하는지 확인.
- 이동 후 에디터에 해당 예제 코드가 올바르게 표시되는지 확인.

## 교정 사항
- 초기 설계 시 `codeLines`를 `DebuggerPage` 내부 상수로 두었으나, 동적 주입을 위해 `initialCode` 상태를 `useLocation().state`로부터 읽어오도록 수정함.
- `ExamplesPage`에서 버튼 클릭 시 `useNavigate`를 통해 코드를 `state`로 전달하는 방식이 가장 깔끔하다고 판단하여 적용함.
