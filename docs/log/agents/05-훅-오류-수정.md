# 05. 훅 호출 순서 및 개수 오류 수정 (Rendered more hooks)

## 사용한 에이전트 도구
- `replace`
- `run_shell_command`

## 위임 범위와 판단 근거
- `src/features/debugger/_hooks/useDebuggerSync.ts`가 자체적으로 전역 상태를 구독하여 불필요하게 훅 호출 횟수를 늘리던 구조를 개선.
- 핫 리로드 시 훅 개수 불일치로 발생하는 React 런타임 에러(`Rendered more hooks than during the previous render`)를 해결하기 위해 중복 훅 호출 제거.
- 추상화 원칙에 따라 `useDebuggerHandler`(Level 3)가 상태를 관리하고 `useDebuggerSync`(Level 2)는 주입받은 데이터를 사용하는 구조로 변경하여 결합도를 낮춤.

## 검증 방법
- `pnpm run lint`: 미사용 임포트 제거 및 린트 통과 확인.
- `pnpm run build`: 전체 프로젝트 타입 체크 및 빌드 성공 확인.
- 구조적 확인: `useDebuggerSync` 내부의 훅 호출이 제거되어 훅 카운트가 안정화됨.

## 교정 사항
- 수정 과정에서 `useDebuggerSync`의 미사용 임포트(`useDebugActionSlice`, `useDebugStateSlice`)가 발생하여 린트 에러가 났으나, 이를 즉시 제거하여 해결함.
