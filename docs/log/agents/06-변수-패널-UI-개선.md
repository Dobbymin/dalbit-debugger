# 06. 변수 패널 UI 개선

## 사용한 에이전트 도구
- `read_file`
- `replace`
- `run_shell_command`

## 위임 범위와 판단 근거
- `src/features/debugger/ui/DebuggerVariablesPanel.tsx`의 디자인이 `MainPage.tsx`의 시뮬레이션 섹션과 일치하지 않아 개선 요청.
- 사용자 경험 일관성을 위해 메인 페이지의 예제 스타일(테두리, 배경색, 레이아웃)을 디버거 페이지의 변수 패널에도 적용.

## 검증 방법
- `pnpm run lint`: 린트 통과 확인.
- `pnpm run build`: 빌드 및 타입 체크 성공 확인.
- 시각적 확인: `Variables (Scope)` 헤더, 각 변수 행의 테두리 및 배경색 적용 확인.
