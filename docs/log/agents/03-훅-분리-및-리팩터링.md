# 03. 훅 분리 및 리팩터링

## 사용한 에이전트 도구
- `read_file`
- `write_file`
- `replace`

## 위임 범위와 판단 근거
- `src/pages/debugger/DebuggerPage.tsx`의 비즈니스 로직을 `useDebuggerHandler` 커스텀 훅으로 분리
- `fsd-rule.md`에 따라 `pages` 레이어는 조합만 담당하도록 리팩터링
- `hooks-rule.md`의 네이밍 규칙(`use{명사}Handler`) 준수
- 상수를 `features/debugger/_constants`로 이동하여 응집도 향상

## 검증 방법
- `pnpm run lint`: 모든 린트 규칙 준수 확인 (성공)
- `pnpm run build`: 모든 타입 체크 및 빌드 성공 확인 (성공)

## 교정 사항
- `useDebuggerHandler`에서 처음에는 `Runtime` 접두사가 붙은 셀렉터 훅을 잘못 사용하여 빌드 에러가 발생했으나, 전체 상태와 액션을 포함하는 `useDebugStateSlice` 및 `useDebugActionSlice`로 교체하여 해결함.
