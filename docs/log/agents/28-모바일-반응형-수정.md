# 28. 모바일 반응형 스타일 수정

## 사용한 에이전트 도구
- Playwright (`browser_navigate`, `browser_resize`, `browser_take_screenshot`, `browser_evaluate`)
- design-system skill (Visual Audit 모드)

## 위임 범위와 판단 근거
- 반응형 적용이 시각적으로 확인되지 않아 Playwright로 375×812 모바일 뷰포트에서 실제 렌더링 스크린샷 촬영
- `browser_evaluate`로 `scrollWidth > clientWidth` 조건으로 overflow 원인 요소 탐색 — 근본 원인 특정에 사용

## 검증 방법
- `browser_evaluate` 스크립트로 모든 DOM 요소 중 `scrollWidth > viewport(375px)` 인 요소 필터링
- 수정 전: `DebuggerPage` 외부 div의 PandaCSS 클래스에 `min-w_0` 미포함 확인
- 수정 후: overflow 요소가 Monaco 내부(예상된 범위)만 남음 확인
- `pnpm run tsc && pnpm run lint` 통과 확인

## 수정 내역

### 근본 원인
`DebuggerPage` 최외곽 div에 `minWidth: 0`이 없어서 flex item이 Monaco editor의 초기 렌더 크기(~800px)를 그대로 수용 → 전체 레이아웃이 모바일 뷰포트를 초과해 팽창

### 파일별 수정

**`src/pages/debugger/DebuggerPage.tsx`**
- 외곽 div에 `minWidth: 0` 추가 (핵심 수정)
- 중간 flex 컨테이너에 `overflowY: { base: "auto", lg: "visible" }` 추가

**`src/features/debugger/ui/DebuggerControls.tsx`**
- 버튼 그룹 div: `flexShrink: 0` → `flex: 1, minWidth: 0, overflowX: "auto"`
- 상태 표시 div에 `flexShrink: 0, whiteSpace: "nowrap"` 추가

**`src/features/debugger/ui/DebuggerVariablesPanel.tsx`**
- 스크롤 영역 div에 `flex: 1, minHeight: 0` 추가
- `minHeight: { base: "180px", lg: "0" }` → `{ base: "150px", lg: "0" }`

**`src/features/debugger/ui/DebuggerOutputPanel.tsx`**
- `height: { base: "180px", md: "200px" }` → `{ base: "150px", md: "200px" }`
- 내부 패딩 `padding: "12px"` → `padding: { base: "8px", md: "12px" }`

## 교정 사항
- 1차·2차 수정 시 overflow 근본 원인 미파악 상태에서 개별 컴포넌트만 수정 → 모바일 반응형 미적용 유지
- 3차에 Playwright `browser_evaluate`로 overflow 원인 요소 직접 탐색 → `minWidth: 0` 누락 확인 후 해결
