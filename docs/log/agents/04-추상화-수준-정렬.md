# 04. 추상화 수준 정렬

## 사용한 에이전트 도구
- `read_file`
- `write_file`
- `replace`

## 위임 범위와 판단 근거
- `src/features/debugger/_hooks/useDebuggerHandler.ts`의 추상화 수준 정렬
- 초기 코드 설정을 담당하는 `useDebuggerSync` (Level 2) 분리
- 실행 진척도를 계산하는 `useDebuggerProgress` (Level 2) 분리
- `useDebuggerHandler`를 Level 2 훅들을 조합하는 Level 3 훅으로 리팩터링하여 가독성 및 유지보수성 향상

## 검증 방법
- `pnpm run lint`: 모든 린트 규칙 준수 확인 (성공)
- `pnpm run build`: 모든 타입 체크 및 빌드 성공 확인 (성공)

## 교정 사항
- `useDebuggerHandler` 내의 저수준 로직(`useEffect`를 이용한 초기화, `useMemo`를 이용한 계산)을 각각 `useDebuggerSync`, `useDebuggerProgress`라는 Level 2 훅으로 격상시켜 추상화 수준을 일치시킴.
