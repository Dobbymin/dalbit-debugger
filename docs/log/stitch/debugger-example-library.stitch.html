짝수 홀수 판별기

입력된 숫자가 짝수인지 홀수인지 판별하는 기본적인 조건문 예제입니다.

num = 7
if num % 2 == 0:
    print("짝수")
else:
    print("홀수")

학점 계산기

점수에 따라 A, B, C, D, F 학점을 부여하는 다중 조건문 예제입니다.

score = 85
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'

1부터 5까지 합계 구하기

POPULAR

for 루프를 사용하여 누적 합을 계산하는 과정을 단계별로 확인합니다.

total = 0
for i in range(1, 6):
    total += i
print(total)

구구단 출력

중첩 for 루프의 동작 방식을 이해하기 위한 기본 예제입니다.

for i in range(2, 4):
    for j in range(1, 4):
        print(f"{i} * {j} = {i*j}")

functions 함수

팩토리얼 (재귀)

재귀 함수의 호출 스택(Call Stack)이 쌓이는 과정을 시각적으로 확인합니다.

def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n-1)
