## **주제: 달빛약속을 활용한 자유 웹앱 개발**

호랑에듀가 사용하고 있는 한국어 프로그래밍 언어 '달빛약속'의 기능을 활용하여, 자유 주제의 웹 애플리케이션을 개발해주세요.

런타임 실행, AST 분석, 파서 활용, 에디터 통합 등 `@dalbit-yaksok/core`의 어떤 기능이든 활용할 수 있으며, 주제와 방향은 자유입니다.

## **주제 예시**

아래는 참고를 위한 예시이며, 이 중 하나를 선택하셔도 되고 다른 방향으로 진행하셔도 됩니다. 주제에 관해서는 패널티도 베네핏도 없습니다.

- 달빛약속 코드를 실행하는 플레이그라운드
    - 음악을 만드는 플레이그라운드
    - 캔버스/DOM을 조작하여 간단한 게임이나 연극을 개발하는 플레이그라운드
    - 위 외에도 자유롭게 구성 가능
- 한글코딩 문법을 배울 수 있는 인터랙티브 튜토리얼
- 달빛약속 코드의 실행 과정을 이해할 수 있도록 시각적으로 보여주는 디버거
- 달빛약속 코드과 흐름도/순서도를 변환하는 시각화 도구
- 그 외 자유 주제

## **기술 요구사항**

- 필수 사용: React / PandaCSS, Vite 8
- 달빛약속 패키지: https://dalbit-yaksok.postica.app
- 코딩 에이전트: Claude Code, Cursor, Codex 등 코딩 에이전트를 필수로 사용해주세요 (아래 "에이전트 협업 기록" 참고)
- 달빛약속 런타임 수정: 런타임에 수정이 필요한 경우 pnpm patch 기능을 사용하여 진행해주세요
(Repository Fork 금지)
- 배포: 배포 URL이 있으면 좋지만, pnpm dev로 로컬에서 실행 가능하면 충분합니다

### **3. 에이전트 협업 기록**

코딩 에이전트를 활용한 과정을 작업 스코프별로 개별 파일로 기록해주세요.

> 예: `docs/agent/01-초기-구조-설계.md`, `docs/agent/02-런타임-연동.md`, ...

각 파일에 아래 내용을 포함해주세요:

- 사용한 에이전트 도구
- 에이전트에게 위임한 작업의 범위와 그 판단 근거
- 에이전트의 산출물을 검증한 방법
- (해당하는 경우) 에이전트가 잘못된 방향을 제시했을 때 이를 교정한 방법

### **4. 에이전트 환경 구성**

에이전트에게 제공한 시스템 프롬프트와, 에이전트에 연결하여 사용한 MCP 서버 및 스킬이 있다면 함께 제출해주세요.

- 시스템 프롬프트: `CLAUDE.md`, `AGENTS.md`, `.cursorrules` 등
- MCP 서버/스킬: 사용한 MCP 서버나 스킬의 목록과 용도
